# Machine Learning

Repository phục vụ cho việc **học tập và thực hành Machine Learning**.

## Mục tiêu

* Tìm hiểu các kiến thức cơ bản về Machine Learning.
* Thực hành các thuật toán và mô hình học máy.
* Lưu trữ bài tập, code và các project trong quá trình học.

> Repository được sử dụng cho mục đích học tập và nghiên cứu.
